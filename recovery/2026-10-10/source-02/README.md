# Recovered product source: tranche 02

This archive preserves 20 source artifacts as inert text under this directory.
All GDScript and JSON snapshots end in `.txt`. No runtime files are replaced.

- **10 original-hash-exact enemy artifacts:** four modules, role data, one fixture,
  and four test suites. Their bytes match the historical SHA-256 record from
  2026-10-10 11:37 UTC, recovered in `verified-original-hashes-1230.json`.
  This later digest evidence supersedes the earlier unverified status labels.
- **7 reconstructed world-storage tests and fixtures:** complete recorded source
  and visible edits, but no historical hashes exist in the available evidence.
- **3 reconstructed existing contracts/fixture sources:** complete recorded read
  outputs, also without historical hashes. Their recorded observation times are
  in the source manifest; they are not asserted to be the latest project state.

`SOURCE-MANIFEST.json` records original paths, provenance classes, byte counts,
SHA-256 values and Git blob IDs. Fresh preservation hashes alone do not establish
historical identity for the 10 transcript-only artifacts.

The four storage production modules and every other path already preserved in
tranche 01 are excluded. This tranche does not supply a full Core, original UID
sidecars, complete golden outputs, or a restored runnable project. Referenced
dependencies and integration still require separate recovery and validation.
No product code or tests were executed for this preservation. Earlier reported
test successes do not establish that these files form a newly integrated game.
