# Original raster generation prompts

Built-in image generation was used for character, prop, icon, UI-panel, illustration and combat-effect artwork. The exact selected originals are retained under assets/art/source. Production files use reproducible nearest-neighbor atlas packing, palette mapping and alpha cleanup. Functional danger masks are separately authored as exact per-pixel mathematical raster diagrams. Audio uses a separately authored original score and waveform synthesis.
